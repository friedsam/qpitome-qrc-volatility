# Hardware and finite-shot results

Keep three evidence classes separate:

1. exact-state simulation
2. finite-shot simulator studies
3. actual QPU execution

Priority studies:

- true multinomial bitstring sampling at 1000 shots
- exact-train to noisy-test transfer
- noisy-train to noisy-test evaluation
- Aquila readiness and selected hardware MVP windows
- actual QPU feature discrepancies and local ordering preservation

Hardware results should always include shots, task count, estimated credits or cost, and the exact simulator reference used for comparison.
