# Experimental results

Historical architecture and readout probes are kept in `results/tables/` and indexed here.

- Early regime-layer analysis: `phase3_clean_*`
- RF-QRC tail probe: `phase3_rf_qrc_tail_probe_*`
- One-QRC/two-head study: `phase3_one_qrc_two_head_*`
- Structured level/rate RF-QRC: `phase3_structured_level_rate_rf_qrc_*`

The one-QRC/two-head q95 validation split was degenerate, so that q95 classifier result is not evidence.

The structured level/rate alternatives did not beat the ring control under the experiment's original gate.

New exploratory studies should write to `results/experimental/<experiment_name>/` or remain in `scratch/` until intentionally promoted.
